# Support

KGRTC is an experimental research project. Questions, documentation corrections, and reproducible analysis are welcome.

## Where to ask

Use GitHub Issues for:

- reproducible bugs;
- documentation problems;
- feature requests;
- build or test failures; and
- research questions that benefit from public discussion.

For security vulnerabilities, follow [`SECURITY.md`](SECURITY.md) instead of posting sensitive details publicly.

## Before opening an issue

Please check:

1. the README and relevant documents in `docs/`;
2. existing issues and pull requests; and
3. the latest code/tests for the behavior you are reporting.

A useful issue includes:

- OS and architecture;
- Rust version;
- repository commit or release version;
- exact command or API call;
- expected behavior; and
- observed behavior.

For research results, include the experiment parameters and enough information for another person to reproduce the result.
